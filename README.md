# 🧠 Когнитивный трекер

> **Интеллектуальная система диагностики и оценки риска развития болезни Альцгеймера на основе когнитивных тестов**

---

## 📌 О проекте

**Когнитивный тест** — это веб-приложение для самостоятельной оценки когнитивных функций (память, внимание). Система включает три стандартизированных теста, сохраняет историю тестирований, отслеживает динамику и выдает персонализированные рекомендации.

### 🔍 Актуальность

Болезнь Альцгеймера является одной из основных причин деменции у пожилых людей. Ранняя диагностика крайне важна, но существующие методы (МРТ, анализы) дороги и недоступны в небольших городах. Данный проект предоставляет **доступный скрининговый инструмент** для первичной оценки когнитивных функций.

---

## 🧪 Тесты

| Тест | Что оценивает | Оценка |
|------|---------------|--------|
| 📝 **Запоминание слов** | Кратковременная вербальная память | 0–10 баллов |
| 🖌️ **Рисование часов** | Конструктивный праксис, внимание | 0–3 балла |
| 🐾 **Назвать животных** | Семантическая память | количество уникальных названий |

---

## 🧠 Экспертная система

Система использует **продукционную модель** (правила вида «ЕСЛИ – ТО»):

- **П1–П3** — оценка базового уровня (хорошо / средне / плохо)
- **П4–П6** — анализ динамики между тестированиями

На основе накопленной истории система формирует персонализированную рекомендацию и строит график динамики.
